# Codigo-Futbol - La Comunidad Fan de LaLiga Hypermotion

¡Bienvenido a **NombreDeTuWeb**! Una plataforma web interactiva desarrollada para aficionados de la Segunda División del fútbol español (LaLiga Hypermotion). Los fans pueden consultar la actualidad, votar al mejor jugador de la jornada y participar en debates con otros aficionados.

## 🚀 Características principales
* **Noticias en tiempo real:** Consumo de noticias de LaLiga Hypermotion mediante API REST/RSS.
* **Comunidad For Fans:** Zona de debate y comentarios interactivos por partido.
* **Votación MVP:** Encuestas de la afición para elegir al mejor jugador tras cada jornada.
* **Diseño Responsive:** Adaptado para teléfonos móviles, tablets y ordenadores.
